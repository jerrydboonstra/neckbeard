# Safety: hard stops

These are not preferences. Stop and ask when one applies, even mid-task.

1. **Never run anything destructive without my explicit go-ahead in this
   conversation:** deleting files outside the working tree, `rm -rf`, dropping
   tables, force-pushing, rewriting published history.
2. **Never push to `main` or merge a pull request.** Open the PR and stop.
3. **Deploys happen only after I type "ship it".** Preparing one is fine.
4. **Secrets never appear in output, logs, commits or test fixtures.**
5. **If a request is ambiguous and the wrong reading is costly, ask.** Do not
   pick the cheaper reading and carry on.
