A sentence is a conflict when it does one of these:
1. It tells the model to do something a reader rule forbids, or not to do something a reader rule requires, in a situation where both apply.
2. It permits, with no limit, an action a reader rule forbids in some cases. Example: "You may try the same action, on your own judgement" against a rule that forbids repeating an action that failed destructively. The unlimited permission is the conflict; the report asks for a limit to be added (for example "only if it isn't destructive").

It is not a conflict when:
- The reader rule governs a different situation (a session the plugin starts is not a subagent dispatch, for example).
- The sentence permits the action only inside a limit that keeps it clear of the cases the reader rule forbids.
- It only repeats, or is stricter than, a reader rule.
